# TimeWorth mobile UI preview

A buildless, interactive design preview for the Android TimeWorth app. Open `dist/index.html` through a static HTTP server. All financial records and schedules are fictional demonstration data; browser changes stay in localStorage. No account connections, bill uploads, analytics, or external assets are used.

Views: Home, Ledger, Plans, Profile. Interactions: hourly-rate settings, purchase/work-time calculator, example installment schedules, wish saving, duplicate-aware demo import, manual expenses, goals, light/dark appearance, reset.

This preview is not an Android APK. Real import adapters, database, notifications, Android packaging and application updates are separate implementation work.
