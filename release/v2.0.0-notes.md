# TimeWorth 2.0.0 · 时间，值得

从日常消费记账切换为不记流水的时间价值与未来规划。正常覆盖升级保留原有应用数据：同一个包名 `dev.h516.timeworth`、原签名证书、`versionCode 2`。

## 新增

- 首页：基础／真实时薪、近期还款、**估算可安排金额**。它不等于银行账户余额，不推断缺失的财务数据。
- 算一算：商品价格换算工作时间、一次付清与含息费的分期比较。默认不保存计算结果。
- 未来：还款时间线、目标进度、心愿清单和可调整的生活费预留。
- 多张花呗／京东白条截图：Android 设备端中文 OCR，识别结果必须核对日期、平台、应还总额才可入库；支持去重、明确更新和导入后撤销。只形成还款计划，不形成消费流水。
- 方案比较：换工作、通勤、买车、租房的现金／时间价值差异，缺失输入显示未知，不编造结果。

## 数据保护与恢复

- 0.1.0 原消费记录留在设备与 JSON 备份中，2.0 主界面不提供记账入口；设置中提供旧记录只读查看。
- 安装升级**不要卸载旧 App 或清除应用数据**。建议先在旧版导出 JSON，再进行原位覆盖安装；恢复备份前会验证数据并二次确认。
- 截图只在设备端读取并处理，不保存截图本身。Google ML Kit 可能发送 SDK 运行指标；无外部付费识别服务。

## 安装与验证边界

- 下载 `timeworth-2.0.0.apk`（不要下载 Source code），Android 8.0 及以上。
- 发布流水线使用已有受保护的**原始签名密钥**，验证 APK 包名、原证书、版本和完整性；不是预览包，不会切换应用标识。
- 云端自动执行计算与导入规则测试、Chromium 交互检查、Android 真正构建和签名校验。真机安装、从 0.1.0 覆盖升级及真实花呗／白条不同截图版式的识别准确率，**尚未通过实体手机验证**；不要将云端通过等同于实体机验收。
