## 下载与安装

在本页附件（Assets）中点击 **timeworth-0.1.0.apk**，下载后打开安装。支持 Android 8.0 及以上，约 2.4 MB。Source code ZIP / tar.gz 是源码，不用于安装。此仓库私有，需要登录有访问权的 GitHub 账号。

## 这版可以做什么

填写工资与工时、查看时薪，把消费换算成工作时间；管理工资流水、分期、心愿与存钱目标，导入账单及导出/恢复 JSON 备份。离线使用，无需 App 登录，首次打开不带演示账单。

## 安装与数据

使用项目原签名，包名 dev.h516.timeworth，版本 0.1.0 / versionCode 1，已关闭调试模式。若之前安装的是包名 dev.h516.timeworth.preview 的体验包，请先导出 JSON，再在新包恢复；两者包名不同。卸载或换机前请导出备份。
