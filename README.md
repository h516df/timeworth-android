# TimeWorth Android

把工作、时间、收入、消费和生活目标联系起来的安卓手机 App。

> 当前状态：可交互手机网页体验版 03；尚无原生 Android App 工程或 APK。

## 产品方向

帮助用户理解一份工作的实际时薪、一笔消费对应的工作时间，以及消费和分期如何影响未来的结余与生活目标。

- **平台**：安卓手机。
- **视觉偏好**：苹果式的清晰排版、充分留白、细腻层次和自然动效，兼顾安卓系统操作习惯。
- **数据方向**：优先本地保存、免登录，支持备份、恢复和迁移。
- **复用原则**：评估已有项目和依赖，核实实际能力与许可证后复用。

## 当前体验流程

[手机打开网页体验版](https://timeworth-mobile-preview.cloudyloom133.chatgpt.site)：看月底预计余钱 → 工资到账时确认金额 → 查看接下来应还与正在攒的期待。

减少步骤和操作成本是首要原则，不强制分类预算或逐日手动记账；收录支持本机账单文件与文字，安卓自动采集仍待实现。源码和计算边界见 [原型说明](ui-preview/README.md)，当前任务状态见 [HANDOFF](HANDOFF.md)。

花呗、京东白条是重要需求。实际文件导入格式、消费与分期数据的可获得性仍待验证；目前不承诺完整自动同步。

## 开发状态

技术栈、最低安卓版本、应用包名、正式中文名称、发布方式和项目许可证尚未确定。原生 App 尚无构建命令或 APK；网页功能与验证边界见原型说明。

已确定需要供他人使用，并支持应用内检查更新。当前仓库保存私有源码；公开安装包和更新信息的分发渠道将在发布阶段配置。仓库中的手动环境检查工作流只验证 GitHub 托管运行器的基础工具，不构建或发布 App。

执行方式已确定为**纯云端**，不依赖用户本地电脑。公开分发复用已有 `h516df/app-releases`，TimeWorth 使用独立的 `timeworth` 入口。签名 Secrets 已经通过云端连接写入 GitHub，并通过证书指纹、临时文件签名和验签检查；实际 APK 构建和安装尚未开始，详见交付文档。

真实工资、个人账单、账号密钥、签名文件和私人备份不应提交到仓库。测试数据应使用明确标注的合成数据。
