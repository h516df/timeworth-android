# UI / UX 方向

## 设计目标

安卓手机 App，采用用户偏好的苹果式清晰层级、留白、细腻列表和自然动效。安卓的返回手势、文件选择、键盘、通知和系统安全区域遵循平台习惯。

不使用未经授权的苹果字体、图标或其他素材；具体字体、图标和资源选型待开发时核实许可。

## 视觉方向

- 浅色以米白、浅灰和深色文字为基础，搭配柔和主题色。
- 金额为主信息，对应工作时间为辅助信息。
- 大标题、统一间距、细腻分隔线和圆角卡片，保持稳定的信息层级。
- 半透明或模糊效果适量使用，并考虑安卓设备性能与可读性。
- 深色模式、系统字体缩放、足够对比度和可操作触摸区域。
- 红色表示明确异常或逾期，不对正常消费施加负面评价。
- 动效服务于状态变化和操作反馈，尊重减少动画的系统偏好。

## 信息架构建议

底部四个入口：

1. **首页**：时薪、当月消费、应还、预计结余、目标和快捷操作。
2. **账本**：交易列表、账户、分类、导入和退款。
3. **计划**：分期日历、愿望、目标和购买模拟。
4. **我的**：工作档案、计算口径、备份和设置。

工作档案也可从首页时薪卡直接进入。

## 首次使用

先填到手收入与工作安排，立即显示时薪。随后按需补充通勤、加班、账户余额、欠款和账单。允许跳过非必要步骤，信息不足时明确说明哪些结果暂不可计算。

## 首批关键页面建议

- 首页概览。
- 工资与工时设置。
- 消费金额输入与即时换算。
- 账单导入预览与核对。
- 分期列表及详情。
- 购买影响预览。

空状态、解析失败、重复数据、撤销、键盘遮挡、长文本和大字体属于这些页面的完整体验范围。

## 参考方向

借鉴苹果“健康”的概览与逐层查看、“钱包”的交易层级、“提醒事项”的清单与进度，以及“计算器”的清晰输入。最终布局和组件应为本项目独立设计。
