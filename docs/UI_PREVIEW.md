# 网页体验版 03：围绕月底余钱，减少操作

[手机打开预览](https://timeworth-mobile-preview.cloudyloom133.chatgpt.site)，保持原有私有访问范围。当前源码在 `ui-preview/dist`；静态服务即可打开，不需要构建。完整交接见 [HANDOFF](../HANDOFF.md)，计算边界见 [原型说明](../ui-preview/README.md)。

本版移走首页分类预算和日常手动记账入口，突出工资到账、月底预计余钱、接下来的应还。应还支持任意平台一句话录入；心愿使用图片收藏卡，开始攒钱后才显示存入进度；四套主题点一下即应用。设置页不再放无功能头像和口号。

历史账单支持本机 CSV / Excel 及文字收录，正常记录批量确认，疑似重复默认跳过。CSV 是账单表格文件，不要求用户自行编写。其他来源可自行命名，但平台专用格式仍需要真实脱敏样本验证。网页不能监听支付通知；通知示例只是明确标注的文字体验，安卓端采集待实现。

参考 Android NotificationListenerService、AutoAccounting 的采集路径，以及 Copilot Money 的收入/例外核对；SheetJS CE 用于本机 Excel。来源和许可已记录在原型 README；没有复制自动记账项目代码或宣称完成插件集成。

初始记录和费率仍为演示，修改与自选照片保存在当前浏览器。月底数字是基于现有数据的估算，缺漏会影响准确性；范围不是统计置信区间，曲线是注明的示意图。本轮没有生成 APK，也未触碰签名 Secrets 或安装包分发。
