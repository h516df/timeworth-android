# 手机交互体验版 02

[手机打开预览](https://timeworth-mobile-preview.cloudyloom133.chatgpt.site)（当前账号访问，保持原有私有权限）。源码在 `ui-preview/dist`，无需构建，通过静态 HTTP 服务打开。

本版按反馈补齐：通勤分钟点选与滑杆、单项编辑、全部导入记录可选与重复核对、CSV 浏览器内读取、可编辑分期与逐期还款、心愿与目标管理、存入取出、分期利息及手续费计算、数据备份恢复。视觉参考 Apple 的材料与层级规范，功能参考 Cashew；未复制其代码。

相关功能已在云端浏览器验收，含 360/390/430/1280px 布局。时薪按统一口径计算；还款不重复记为支出；本月目标净存入计入预留。详见 `ui-preview/README.md` 中计算边界与参考来源。

初始数据与费率仍为演示；个人修改仅保存在当前浏览器。真实支付账户、平台 PDF/OCR、跨设备同步与安卓 APK 尚未实现。之前的 UI 预览数据会尽可能迁移，通勤小时转换为分钟；本次未触碰签名或分发设置。
