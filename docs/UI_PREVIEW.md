# 网页体验版 04：当月工资留下多少

[手机打开预览](https://timeworth-mobile-preview.cloudyloom133.chatgpt.site)，保持原有私有访问范围。源码在 `ui-preview/dist`，直接静态服务，无构建步骤。完整交接见 [HANDOFF](../HANDOFF.md)，计算边界见 [原型说明](../ui-preview/README.md)。

首页只跟踪当月工资、当前留下和月底预计留下。历史存款、其他收入和旧余额校准不增加工资；目标转存不算消费。支出默认来自本月工资，可改为其他资金。月底估计依赖已收录的应还、固定支出和日常消费速度，不是账户实时余额或完整资产负债表。

分期可填含息费总还款，或每期金额 × 期数，自动和原价比较。例如 6000 → 12 × 520 = 6240，多付总息费 240，不重复加息。无法仅凭总额分离纯利息与手续费。工作时间显示天、工作月和收入对应自然天，不代表寿命损失。

工资流向先看摘要，明细按需打开；心愿可独立自定义图标/表情/图片，与封面分开。四种皮肤改变材质、字体、布局和导航，并支持密度与本机背景。选择菜单保持在当前场景，底栏过渡可被快速连点打断，尊重减少动态效果。

账单仍支持本机 CSV/Excel 与文字批量收录、任意来源名称。网页没有跨 App 通知权限；真实平台自动同步、ZIP/加密/PDF/OCR 和原生 Android 仍待实现。历史账单兼容需脱敏样本验证。初始数据为演示，修改与照片存在当前浏览器，无后端。

调研参考 Apple motion/pickers/segmented controls、Copilot Money，以及 Android NotificationListenerService 和 AutoAccounting 的采集路径。SheetJS CE 读取本机 Excel；来源与许可见原型 README，未复制自动记账项目代码。
